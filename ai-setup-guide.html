BlogPost — Настройка AI-провайдеров

Пошаговая инструкция для подключения реальных нейросетей.

Шаг 1: Получите Supabase Access Token

1. Откройте Supabase Dashboard → Tokens

2. Нажмите "Generate new token", дайте имя "BlogPost CLI"

3. Скопируйте токен — он понадобится ниже

Шаг 2: Получите YandexGPT API Key

1. Откройте Yandex Cloud Console

2. Создайте облако (если нет) → перейдите в него

3. Найдите FOLDER_ID — он на главной странице облака (строка вида b1gxxxxxxxxxxxxxxxxx)

4. Слева → "Сервисные аккаунты" → создайте аккаунт → добавьте роль "ai.editor"

5. На странице сервисного аккаунта → "Создать новый API-ключ" → скопируйте API Key

Шаг 3: Запустите команды в терминале

Откройте терминал (PowerShell) в папке проекта и выполните команды по очереди. Замените значения в кавычках на ваши.
3.1 Войдите в Supabase:
npx supabase login --token ВАШ_SUPABASE_TOKEN
3.2 Установите секреты для Edge Functions:
npx supabase secrets set --project-ref udfqkkeupibrhighbizj YANDEX_GPT_API_KEY=ВАШ_YANDEX_API_KEY YANDEX_FOLDER_ID=ВАШ_FOLDER_ID
3.3 (Опционально) Для генерации изображений через FusionBrain:
npx supabase secrets set --project-ref udfqkkeupibrhighbizj FUSIONBRAIN_API_KEY=ВАШ_КЛЮЧ FUSIONBRAIN_API_SECRET=ВАШ_СЕКРЕТ

Ключи FusionBrain: fusionbrain.ai/keys

3.4 Деплой Edge Functions:
npx supabase functions deploy --project-ref udfqkkeupibrhighbizj

Готово!

После выполнения команд AI-генерация на сайте будет работать через реальные нейросети YandexGPT.

Проверьте: откройте blogpost-chi-gilt.vercel.app → Войдите → Генерация контента → введите тему → "Сгенерировать"
