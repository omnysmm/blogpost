Deploy telegram-publish Edge Function

1. На открывшейся странице Supabase нажмите "Create a new function"
2. Введите имя: telegram-publish
3. Удалите весь код из редактора и вставьте этот (нажмите на блок кода — он скопируется):
Нажмите на блок кода ниже, чтобы скопировать его целиком
// Supabase Edge Function: telegram-publish import { serve } from 'https://deno.land/std@0.177.0/http/server.ts' serve(async (req) => { if (req.method === 'OPTIONS') { return new Response(null, { headers: { 'Access-Control-Allow-Origin': '*', 'Access-Control-Allow-Methods': 'POST', 'Access-Control-Allow-Headers': 'Content-Type, Authorization', }, }) } try { const { token, chatId, text, imageUrl } = await req.json() if (!token) { return jsonResponse({ success: false, error: 'Не указан токен бота Telegram' }, 400) } if (!chatId) { return jsonResponse({ success: false, error: 'Не указан Chat ID' }, 400) } let result if (imageUrl) { result = await callTelegram(token, 'sendPhoto', { chat_id: chatId, photo: imageUrl, caption: (text || '').slice(0, 1024), parse_mode: 'HTML', }) } else { result = await callTelegram(token, 'sendMessage', { chat_id: chatId, text: (text || '').slice(0, 4096), parse_mode: 'HTML', }) } if (result.ok) { return jsonResponse({ success: true, messageId: result.result?.message_id }) } else { const errorMsg = translateTelegramError(result.description || 'Неизвестная ошибка') return jsonResponse({ success: false, error: errorMsg }) } } catch (error) { return jsonResponse({ success: false, error: 'Ошибка сервера: ' + error.message }, 500) } }) async function callTelegram(token, method, body) { const response = await fetch('https://api.telegram.org/bot' + token + '/' + method, { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify(body), }) return response.json() } function translateTelegramError(msg) { const lower = msg.toLowerCase() if (lower.includes('chat not found')) return 'Чат не найден. Проверьте Chat ID и убедитесь, что бот добавлен в канал/группу.' if (lower.includes('bot was blocked')) return 'Бот заблокирован пользователем.' if (lower.includes('not enough rights')) return 'У бота недостаточно прав. Назначьте бота администратором.' if (lower.includes('bad request')) return 'Неверный запрос. Проверьте формат сообщения и Chat ID.' if (lower.includes('unauthorized')) return 'Неверный токен бота. Проверьте API Key в настройках.' if (lower.includes('forbidden')) return 'Доступ запрещён. Бот не имеет прав на отправку сообщений.' return 'Telegram: ' + msg } function jsonResponse(data, status) { return new Response(JSON.stringify(data), { status: status || 200, headers: { 'Content-Type': 'application/json', 'Access-Control-Allow-Origin': '*' }, }) }
4. Нажмите "Deploy"
Код скопирован!
